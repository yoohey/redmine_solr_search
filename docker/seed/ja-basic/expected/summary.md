# 検索の期待値（ja-basic）

`seed/expect.sh ja-basic`で生成（手で直さない）。単語は`words.yml`、全件のIDは`expected.yml`。

- 一致の条件：本文・件名・注記・ファイル名・添付の中身などに、その語が部分文字列として含まれる（NFKC正規化、大文字小文字を区別しない）。検索エンジンが理想的に動いたときの結果
- 権限：Redmineの判定そのもの（プライベートチケット、プライベート注記、プロジェクトのメンバー）
- 検算：添付の中身を除いた部分は、Redmine標準の検索と全ユーザー×全単語で比べた。**すべて一致**
